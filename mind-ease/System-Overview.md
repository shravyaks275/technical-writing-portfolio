# Mind Ease — System Overview

## 1. Introduction

Mind Ease is a browser-based mental wellness and stress-relief companion implemented as a collection of static HTML pages with embedded JavaScript and CSS.

The application provides several independent wellness-oriented features, including:

- Mental-health survey
- Guided meditation content
- Stress-relief exercises
- Breathing exercise
- Mood tracking
- Browser-based speech recognition
- Simulated therapist interaction
- Video resources
- Color-matching game
- Memory game
- Mood-based leaderboard
- Client-side login demonstration

The repository does not contain a server-side application, database, REST API, frontend framework, package-management configuration, or external AI service implementation.

The application is therefore primarily client-side and can be run as a static website.
